# Verify Changes

Run before commit or PR when using AI-assisted edits.

## Required

1. Read skill **`verify-changes`** and follow it.
2. Optionally launch **Task → verifier** for an independent pass/fail report.

## Stop

Report summary: tests passed or failed, what was checked.
