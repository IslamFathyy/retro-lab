# Publish dev-guardrails

## Cursor public marketplace

1. Push `retro-lab` to GitHub (includes `plugins/dev-guardrails/` and `.cursor-plugin/marketplace.json`).
2. Complete clean install test in [`docs/plugins/dev-guardrails.md`](../../docs/plugins/dev-guardrails.md).
3. Open **https://cursor.com/marketplace/publish**
4. Submit repository URL: `https://github.com/IslamFathyy/retro-lab`
5. In submission notes, specify plugin path: `plugins/dev-guardrails`

Or publish a dedicated repo with the plugin at root (single-plugin layout).

## Integrant org marketplace

1. Share `.cursor-plugin/marketplace.json` with marketplace admin.
2. Attach security checklist from `docs/plugins/dev-guardrails.md`.
3. Record approval date in that doc when listed.

## After approval

Update goal tracker to 100% and link live listing URL in `docs/plugins/dev-guardrails.md`.
